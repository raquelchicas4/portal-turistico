Portal Turístico de Santa Ana

Proyecto de un portal web turístico enfocado en Santa Ana, El Salvador. El objetivo es mostrar información sobre destinos turísticos, lugares de interés y fotografías del departamento.

Integrantes:

Arturo
José Carlos Manzanares
Raquel Chicas

Distribución del trabajo:

`index.html` — Raquel Chicas
`destinos.html` — Arturo
`galeria.html` — José Carlos Manzanares
contacto.html` — Los tres integrantes

Páginas del portal:
El sitio estará compuesto por cuatro páginas enlazadas entre sí:

index.html
destinos.html
galeria.html
contacto.html

El menú de navegación será el mismo en todas las páginas:

Inicio | Destinos | Galería | Contacto

Estilos:
Todas las páginas utilizarán el archivo `css/estilos.css` para mantener un diseño uniforme. También compartirán el mismo encabezado, menú de navegación y pie de página.

Trabajo con Git:
La rama `main` contendrá la versión principal del proyecto. Cada integrante trabajará en una rama propia:

pagina/inicio
pagina/destinos
pagina/galeria
pagina/contacto

No se realizarán cambios directamente en `main`. Los cambios se realizarán en las ramas personales y posteriormente se subirán a GitHub mediante `git push`.

Commits:
Cada integrante deberá realizar al menos tres commits con mensajes claros que describan los cambios realizados.

Pull Request:
Cuando una página esté terminada, el integrante deberá crear un Pull Request desde su rama hacia `main`. Otro integrante revisará el trabajo y realizará al menos un comentario antes de aprobarlo y realizar el merge.
